# 公众号运营分析 · qianjin-wechat-analyzer

**专业公众号运营诊断系统**：内容分析 × 数据洞察 × 选题策略 × 运营规划。

输入一个公众号，输出一份可执行的运营改善方案。

## 核心能力

| 模块 | 说明 |
|------|------|
| 📊 **账号定位分析** | 赛道判断、受众画像、内容调性、人设评估 |
| 📝 **文章内容分析** | 选题/标题/结构/写作风格/金句密度 多维度深度诊断 |
| 📈 **阅读数据诊断** | 阅读量/点赞/在看趋势、爆款特征提炼 |
| 🎯 **选题与方向建议** | 可拓展选题TOP5、差异化策略、标题优化方案 |
| 🗓️ **运营计划** | 4周排期方案、增长策略、互动提升、变现建议 |

## 分析理念

**内容为核**——即使没有阅读数据，单靠分析文章内容也能给出60%以上有价值的运营建议。阅读数据是锦上添花，不是必要条件。

## 触发方式

- "分析一下这个公众号：XX"
- "给我深度分析一下XX公众号"
- "这个号应该做什么选题？"
- "帮我对比分析XX和YY两个公众号"
- "帮我看下这篇公众号文章质量怎么样"
